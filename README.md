# 🎮 스트리머 워드 타자 디펜스 (Word Typing Defense)

SOOP · 치지직 · 유튜브 라이브 **1인 솔로 스트리머**에 최적화된 **네온 사이버펑크 스타일 타자 방어(산성비) 웹 게임**입니다.
시청자가 채팅으로 `!참여`하면 그 닉네임이 몬스터로 등장하고, 스트리머가 아래 제시어를 타이핑해서 방어합니다.

> **웹 배포 주소**: [https://golddragon0207.github.io/word-typing-defense/](https://golddragon0207.github.io/word-typing-defense/)
> PC 전용(최소 1024×768). 브라우저로 접속 후 바로 플레이하거나 OBS 브라우저 소스로 얹어서 방송할 수 있습니다.

---

## 🎯 주요 기능

### 1. 🏷️ 2단 몬스터 UI (시청자 닉네임 + 제시어)
- **상단 뱃지**: 실제 참여 시청자 닉네임(`🔵SOOP`, `🟢치지직`, `🔴유튜브` 접두사) 또는 `[BOT]` 표식.
- **하단 제시어 상자**: 실제로 타이핑할 제시어. **글자 길이에 맞춰 박스가 자동으로 늘어나** 긴 단어도 깔끔하게 표시됩니다. 흰 글자 + 진한 불투명 상자 + 정수 픽셀 정렬로 **움직이는 중에도 또렷하게** 보이고, 닉네임 뱃지도 불투명 배경으로 가독성을 높였습니다.
- 보스는 금색·확대, 라이브 채팅 문구 몬스터는 보라색으로 구분됩니다.

### 2. 📡 실시간 방송 채팅 연동 (SOOP · 치지직 · 유튜브 동시)
- 방송 주소를 붙여넣으면 채널 ID를 자동 파싱해 연동합니다. **세 플랫폼 동시 연동** 지원. 연동 UI는 **홈 화면 인라인 패널**(접이식)로 배치되며 기본 탭은 **SOOP**입니다.
- 시청자가 채팅에 **`!참여`**를 치면 그 닉네임이 몬스터로 출전합니다.
- **SOOP·치지직 연동은 CORS 우회용 프록시가 필요**합니다. 무료 Cloudflare Worker([`proxy/soop-cors-proxy.worker.js`](./proxy/soop-cors-proxy.worker.js)) **하나**를 **개발자가 한 번만 배포**해 `CONFIG.SOOP_PROXY`/`CONFIG.CHZZK_PROXY`(같은 주소)에 넣어두면, 이후 **스트리머는 방송 URL만 붙여넣으면 자동 연동**됩니다(프록시 조작 불필요). 이 Worker는 SOOP·아프리카·치지직(`api.chzzk.naver.com`·`comm-api.game.naver.com`) 도메인을 허용합니다. 설정법: [`docs/SOOP_연동_설정.md`](./docs/SOOP_연동_설정.md).
  - 치지직은 `live-status`로 채팅방ID를 얻고 `access-token`으로 익명 읽기 토큰을 발급받아 `wss://kr-ss{N}.chat.naver.com`에 연결합니다(성인 인증 방송은 익명 연동 불가).
- 연동 실패·방송 오프라인·프록시 미설정 시 **`[BOT]` 가상 시청자 자동 소환**으로 끊김 없이 진행(Smart Fallback).
- **봇은 스폰 주기마다 한 명씩만 보충**됩니다. 몬스터가 나올 차례에 대기열이 비어 있으면 그 자리에서 `[BOT]`을 한 명 생성하므로, 시작하자마자 대기열이 봇으로 가득 차지 않고 실참여자가 있으면 항상 먼저 등장합니다. 비속어는 자동 필터링됩니다.
- **게임 시작 후 5초 뒤 첫 몬스터 등장**: '게임 시작'을 눌러도 바로 몰려오지 않고 5초 여유를 둬, 그 사이 시청자가 `!참여`로 모일 수 있습니다(`CONFIG.START_SPAWN_DELAY_MS`, 게임 시작에만 적용·스테이지 전환엔 지연 없음).
- **참여자 목록 & 재모집**: 홈 화면 채팅 연동 패널에서 `!참여`한 시청자를 실시간 목록으로 확인. **🗑️ 참여자 초기화** 버튼으로 언제든 비울 수 있습니다. 게임 오버 화면에서 **`🔄 다시 도전하기`를 누르면 방금 판의 참여자 명단을 그대로 유지한 채 즉시 새 판을 시작**합니다(재모집 없이 바로 한 판 더). **`🏠 메인 화면으로`를 누르면 명단이 초기화되고 홈의 채팅 연동 패널이 자동으로 펼쳐져 시청자를 다시 모집**합니다(방송 URL·연결은 그대로 유지).
- **스트리머 닉네임 필수 입력**: 스트리머 닉네임 칸은 연동 패널 안(참여자 명단 바로 위)에 있으며 **반드시 입력**해야 합니다. 빈 값으로 게임을 시작하면 시작이 막히고 패널이 펼쳐지며 입력칸으로 안내합니다.
- **공정성 장치**: 대기열은 30명 버퍼 + **1인당 최대 2자리**로 제한해, 한 명이 도배해도 여러 시청자가 골고루 등장합니다. 참여자 명단은 **최대 10,000명**까지 누적됩니다.
- **게임 중 대기열 패널**: 좌상단에 다음 소환 순서를 실시간 표시(실참여자는 밝게, 봇은 흐리게).

### 3. 💬 라이브 채팅 모드 & 대기열 누적 (신규)
- 상단 **`💬 라이브 채팅 모드`** 버튼을 켜면 **`!참여`한 시청자의 채팅 문구**가 그대로 타이핑 제시어가 됩니다(게임 중에도 즉시 ON/OFF).
- **채팅 누적 등장**: `!참여`한 시청자의 채팅이 **순서대로 대기열에 쌓여 차례차례 몬스터로 등장**합니다(친 사람 모두 반영). 대형 방송의 채팅 폭주는 큐 상한(30) + 1인당 최대 2자리 제한으로 자동 조절되며, 라이브 문구 몬스터는 좌상단 대기열 패널에 `🔥`로 강조됩니다.
- 이모티콘·특수문자 제거, 비속어 필터, 최대 글자수 컷(모달에서 설정) 후 안전하게 사용하며, 라이브 문구 몬스터는 **보라색**으로 강조됩니다.

### 4. 🎚️ 밸런스 & 난이도 곡선
- 표준(`normal`) 밸런스로 실행됩니다. (별도 난이도 선택 UI는 제거 — 밸런스 테이블 `CONFIG.DIFFICULTY`는 유지되어 값 조정이 가능합니다.)
- **스테이지 간 난이도 점프가 크지 않도록** 낙하·스폰·처치 목표를 완만하게 조정했습니다. 각 스테이지의 최소 클리어 타수가 **약 50 → 60 → 70 → 80 → 90타…** 로 부드럽게 오릅니다(시뮬레이션 검증).
- 스테이지1은 초보(~50타)도 클리어 가능하며(낙하 약 23초·스폰 약 9.5초·처치 8마리), 스테이지가 오를수록 조금씩 더 빠른 타수를 요구합니다.
- 동시 출전 몬스터는 방송 마비 방지를 위해 **최대 15마리로 고정**됩니다.

### 5. ⌨️ 한글 자모 획수 기반 CPM/WPM & 콤보 & 🔥 피버 모드
- 초/중/종성 획수를 정밀 분해해 실시간 타수(CPM/WPM)를 산출합니다.
- 콤보가 쌓여 게이지가 차면 **6초간 점수 2배** 피버 모드가 발동합니다.

### 6. ♾️ 무한 스테이지 & 5 스테이지 보스전
- 종료 엔딩 없이 패배할 때까지 무한 진행. **5 스테이지마다 WARNING 배너와 함께 보스**가 등장합니다.
- 보스 제시어는 라이브 채팅·단어팩과 무관하게 **'시스템 붕괴' 테마의 고난도 전용 문구 30종**(예: `분산서비스거부공격`, `침입탐지시스템무력화`, `자폭시퀀스카운트다운`)에서 랜덤 출제됩니다. 길고 겹받침이 많아 일반 몬스터보다 타이핑 난도가 높습니다.

### 7. 👑 등급(SSS~D) & 명예의 전당 (최고 도달 스테이지 기준)
- **도달 스테이지 기준 고정 등급**: `SSS ≥ 70 · SS ≥ 50 · S ≥ 34 · A ≥ 27 · B ≥ 22 · C ≥ 10 · D < 10` (0점/0처치 시 D). 게임 목표(방어 지속)·리더보드와 같은 잣대이며, 시뮬레이션으로 **B=평균 타수(300~400타)** 에 오도록 보정했습니다. 신기록 시 `🎉 NEW RECORD!` 연출.
- **🌐 상위 %**: 게임오버 시 등급 뱃지 아래에 글로벌 백분위(`상위 X%`)를 표시합니다. 전체 누적 기록(0점 제외)이 일정 수(기본 50명) 미만이면 `상위 집계 중…`으로 보여주고, 내 점수가 0이거나 Firebase 미설정/오프라인이면 숨깁니다. (점수는 클라이언트 제출값이라 재미용 근사치)
- **🏅 이번 판 MVP**: 게임오버 결과 화면에 몬스터를 가장 많이 낸 실참여 시청자를 MVP로 표시. **집계 기준은 "등장(참여)"** 라 스트리머가 그 몬스터를 못 죽여도 카운트됩니다(봇만 있었던 판은 표시 안 함).
- **명예의 전당은 최고 도달 스테이지 기준 단일 TOP 5**로 표시됩니다(동점이면 점수순). STAGE를 주지표로 강조하고 등급·점수·WPM·날짜를 함께 보여줍니다. **📜 전체 순위 보기** 버튼으로 TOP 5 ↔ 전체 목록을 전환할 수 있습니다.
  - **로컬**: 브라우저 `localStorage`에 최고 도달 스테이지 기준 단일 통합 리스트로 저장(기본).
  - **글로벌**: Firebase Firestore 연동 시 전 스트리머 공유 글로벌 리더보드(미설정 시 로컬 폴백).
- **⏸ 일시정지**: 게임 중 **ESC 키** 또는 **화면의 일시정지 버튼(⏸)**으로 잠깐 멈췄다가 이어서 할 수 있습니다(화장실 등). 멈춘 동안의 시간은 타수(WPM) 계산에서 제외됩니다. (스페이스바는 제시어 입력에 쓰이므로 일시정지 키로 쓰지 않습니다)

### 8. 🖥️ 1024×768 고정 레이아웃 + 비율 스케일 & OBS 크로마키
- **상단바(60px) + 게임 무대(1024×708) = 1024×768**(PC 최소 해상도)에 정확히 맞습니다. 무대의 **내부 논리 해상도를 1024×708로 고정**하고, 무대 전체를 창 크기에 맞춰 **비율을 유지한 채 확대/축소(scale-to-fit)**합니다. 게임 좌표·방어선·몬스터 위치가 창 크기와 무관하게 **절대 리플로우되지 않아**, 창을 키웠다 줄이거나 다른 탭을 다녀와도 게임이 깨지지 않습니다.
- 캔버스 백버퍼는 **실제 표시 크기 × `devicePixelRatio`**로 잡아 어떤 배율·4K/Retina에서도 선명하게 출력됩니다.
- **반응형 상단바**: 창이 좁아지면(<1440px) 7개 컨트롤 버튼이 아이콘만 표시되고, 마우스를 올리면 툴팁으로 이름(토글은 현재 ON/OFF 상태)을 보여줘 넘침 없이 모든 기능을 유지합니다.
- **게임 중 버튼 잠금**: 플레이 중에는 게임을 멈추지 않는 모달 버튼(📝 단어팩·🏆 명예의 전당·☕ 후원·💡 건의사항) 4개가 자동으로 흐려지며 클릭이 막힙니다(실수로 눌러 그냥 지는 상황 방지). 방송 중 즉시 조정이 필요한 **💬 라이브 채팅 모드·📺 OBS 크로마키·🔊 사운드는 잠그지 않아** 언제든 켜고 끌 수 있습니다.
- 상단 **`📺 OBS 크로마키`** 버튼으로 배경 투명화 → 캠/방송 화면 위 오버레이로 사용. 텍스트는 아웃라인 + 그림자로 크로마키 배경에서도 잘 보입니다.
- **탭 백그라운드 보호**: 다른 화면을 보는 동안(탭 숨김)에는 몬스터 스폰을 멈춰, 돌아왔을 때 몬스터가 한꺼번에 몰려 있는 문제를 방지합니다.

## ⚙️ 배포 전 설정 (선택)

정적 호스팅(GitHub Pages)이라 아래 값은 **비워두면 해당 기능만 자동으로 꺼지고 나머지는 정상 동작**합니다.

- **SOOP 라이브 연동**: `js/config.js`의 `SOOP_PROXY`에 배포한 Cloudflare Worker 주소(`.../?url=`) 입력. 비우면 SOOP은 BOT 시뮬레이션으로 폴백. 배포·설정 전체 절차는 [`docs/SOOP_연동_설정.md`](./docs/SOOP_연동_설정.md) 참고. (프로토콜이 비공식이라 실제 방송에서 `SOOP_DEBUG` 로그로 최종 검증 권장)
- **유튜브 라이브 연동**: `js/config.js`의 `YOUTUBE_API_KEY`에 YouTube Data API v3 키 입력. (키에 HTTP 리퍼러 제한을 걸면 배포 도메인에서만 동작하며 로컬에서는 막힘)
- **글로벌 명예의 전당 / 애널리틱스**: `js/config.js`의 `CONFIG.FIREBASE`에 Firebase 웹 앱 설정 입력 + Firestore 보안 규칙 게시(규칙은 `js/globalLeaderboard.js` 상단 주석 참고).
